# Lineare Algebra - Begriffe

## Logik

| Zeichen | Begriff | Beispiel | Definition |
| --------------- | --------------- | --------------- | --------------- |
| (minus mit Haken dran) | Negation | -A | 'nicht A, Wert wird umgedreht' |
| v | Disjunktion | A v B | 'A oder B'; eins muss wahr sein |
| (auf dem Kopf stehend) | Konjunktion | A (v) B | 'A und B'; beide müssen wahr sein |
| => | Implikation | A => B | aus A folgt B; nur falsch, wenn A wahr und B falsch; es darf nichts falsches auf etwas wahres gefolgert werden |
| <=> | Äquivalenz | A <=> B | aus A folgt B und aus B folgt A; nur wahr, wenn beide wahr |
| A(x) | Prädikat | A(x) = x < 30 | x ist an Variable geknüpft und Wahrheitswert macht sich an dieser fest |
| (umgedrehtes E) | Existenz-Aussage | (E)n (element von)N n + 1 = 0 | Es gibt mindestens ein Element, für die folgende Aussage gilt |
| (umgedrehtes A) | All-Aussage | (A)n (element von)N n + 1 > 0 | Für alle n gilt die folgende Aussage |
